# Dinesh Karki — Portfolio

A high-performance, modern portfolio website for a Computer Science student
majoring in AI.

- **Stack:** Astro + Tailwind CSS
- **Deployment:** Vercel (static site generated from GitHub)
- **Theme:** Dark, futuristic purple/indigo, glassmorphism

## Features

- **Responsive navigation** — sticky blurred header with a live Kathmandu
  (NPT, UTC+5:45) time pill, smooth-scroll links, and a scroll-spy that
  highlights the active section.
- **Hero** — two-column layout with a glowing purple aura, a portrait
  monogram, and a typewriter effect cycling through "I'm an AI Engineer".
- **Projects** — glassmorphic cards sourced from `src/data/projects.ts`,
  with GitHub and live-demo links.
- **Expertise** — a categorized tech-stack grid with official brand logos.
- **Resume** — JSON-driven timeline (`src/data/resume.json`) with a
  **Download Resume (PDF)** button. The PDF is generated by
  `scripts/build-resume-pdf.mjs`, which renders the page headlessly into a
  clean A4 document and writes it to `public/dinesh-karki-resume.pdf`.
- **Contact** — Formspree-powered form plus brand-icon links to GitHub,
  LinkedIn, and Gmail.
- **Mobile** — hamburger drawer for navigation on small screens.

## Getting started

```bash
npm install
npm run dev      # http://localhost:4321
```

## Build & preview

```bash
npm run build    # output → dist/
npm run preview  # serve the production build locally
```

## Regenerate the resume PDF

The PDF shipped in `public/` is produced from the live page, not hand-written,
so it always matches the site:

```bash
npm run resume:pdf
```

This runs `scripts/build-resume-pdf.mjs`, which serves the built site, prints
it via headless Chrome, and writes `public/dinesh-karki-resume.pdf`. The PDF is
A4 and fits within two pages.

## Deploy

Deploy from GitHub to Vercel:

1. Push the repository.
2. In the Vercel dashboard, import the repo.
3. Build settings — output directory: `dist`.

No environment variables are required; the contact form uses the Formspree
endpoint configured in `src/data/site.ts`.
